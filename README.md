## 🇧🇷 Português

### Sobre esta pasta

Este diretório reúne as **atividades avaliativas** da disciplina de **Algoritmos e Pensamento Computacional**. Cada atividade fica em sua própria subpasta, com código-fonte e README explicando o que foi feito.

### Atividades

| Pasta | Atividade | Descrição |
|---|---|---|
| [`calculadora-flowgorithm/`](./calculadora-flowgorithm) | Calculadora Universal | Calculadora com 27 funções (mínimo de 20 exigido) desenvolvida no Flowgorithm, incluindo cálculo de IMC e de área de figuras geométricas — [ver README da atividade](./calculadora-flowgorithm/README.md) |

> Novas atividades da disciplina serão adicionadas aqui como novas subpastas, cada uma com seu próprio README.

### Estrutura

```

└── calculadora-flowgorithm/
    ├── Calculadora_Universal.fprg
    ├── LICENSE
    └── README.md
```

## 🇺🇸 English

### About this folder

This directory gathers the **graded assignments** for the **Algorithms and Computational Thinking** course. Each assignment lives in its own subfolder, with source code and a README explaining what was done.

### Assignments

| Folder | Assignment | Description |
|---|---|---|
| [`calculadora-flowgorithm/`](./calculadora-flowgorithm) | Universal Calculator | A 27-function calculator (minimum of 20 required) built in Flowgorithm, including BMI and geometric area calculations — [see assignment README](./calculadora-flowgorithm/README.md#-english) |

> New assignments for this course will be added here as new subfolders, each with its own README.

### Structure

```
desenvolvimento-de-algoritmo-e-pensamento-computacional/
└── calculadora-flowgorithm/
    ├── Calculadora_Universal.fprg
```
