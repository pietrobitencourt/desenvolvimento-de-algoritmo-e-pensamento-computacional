## 🇧🇷 Português

### 📋 Sobre o Projeto

Calculadora universal desenvolvida em linguagem C, reunindo diversas funcionalidades matemáticas e utilitárias em um único programa, acessado por meio de um menu principal. O projeto nasceu como algoritmo no Flowgorithm e foi posteriormente portado para C.

### ⚙️ Funcionalidades

| Nº | Função | Descrição |
|----|--------|-----------|
| 1 | **Cálculo de Área** | Quadrilátero, triângulo, círculo e losango |
| 2 | **Cálculo de IMC** | Índice de Massa Corporal com classificação |
| 3 | **Calculadora Simples** | Soma, subtração, multiplicação, divisão e potenciação |
| 4 | **Conversor de Temperatura** | Celsius para Fahrenheit ou Kelvin |
| 5 | **Par ou Ímpar** | Verifica a paridade de um número |
| 6 | **Cálculo de Desconto** | Valor final de um produto com desconto percentual |
| 7 | **Comparador de Valores** | Identifica o maior entre dois números |
| 8 | **Conversor de Unidades** | Metros para milímetros, centímetros, decímetros, hectômetros e quilômetros |

### 🚀 Como Compilar e Executar

```bash
gcc calculadora.c -o calculadora -lm
./calculadora
```

> O `-lm` é necessário para vincular a biblioteca matemática (`math.h`), usada nas funções de área, IMC e potenciação.

### 🖥️ Requisitos

- Compilador C (GCC recomendado)
- Sistema operacional Windows, Linux ou macOS

## 🇺🇸 English

### 📋 About the Project

A universal calculator built in C, combining several mathematical and utility features into a single program, accessed through a main menu. The project began as a Flowgorithm algorithm and was later ported to C.

### ⚙️ Features

| No. | Function | Description |
|-----|----------|-------------|
| 1 | **Area Calculator** | Quadrilateral, triangle, circle, and rhombus |
| 2 | **BMI Calculator** | Body Mass Index with classification |
| 3 | **Simple Calculator** | Addition, subtraction, multiplication, division, and exponentiation |
| 4 | **Temperature Converter** | Celsius to Fahrenheit or Kelvin |
| 5 | **Even or Odd** | Checks whether a number is even or odd |
| 6 | **Discount Calculator** | Final price of a product after a percentage discount |
| 7 | **Value Comparator** | Identifies the larger of two numbers |
| 8 | **Unit Converter** | Meters to millimeters, centimeters, decimeters, hectometers, and kilometers |

### 🚀 How to Compile and Run

```bash
gcc calculadora.c -o calculadora -lm
./calculadora
```

> The `-lm` flag is required to link the math library (`math.h`), used in the area, BMI, and exponentiation functions.

### 🖥️ Requirements

- C compiler (GCC recommended)
- Windows, Linux, or macOS
